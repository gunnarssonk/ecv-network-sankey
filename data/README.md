# data/

The workbook goes here.

Download `observing-the-gcos-ecvs_v1.0.xlsx` from
<https://doi.org/10.5281/zenodo.21702298> and place it in this directory. The
scripts then find it with no arguments; otherwise pass `--workbook PATH`.

The workbook is archived separately, under CC BY 4.0, and is deliberately not
bundled with this code so that the two stay independently versioned.
